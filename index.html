팀원들과 즉시 공유 & 작업 착수
ai-issue의 핵심 철학

AI는 제안하고,
결정은 사람이 합니다.

AI에게 프로젝트의 모든 권한을 덜컥 맡기지 마세요. ai-issue는 사람과 AI가 가장 건강하게 협업하는 방식을 만듭니다.

AI Source ≠ GitHub Opener

이슈를 발행하는 주체는 언제나 인증된 개발자(당신)입니다. AI는 출처(AI Source)로 투명하게 기재되어 책임 소재를 명확히 합니다.

발행 전 철저한 사전 검토

AI가 작성한 환각이나 불필요한 내용이 없는지 미리보기와 확인 절차를 거치므로 깔끔하고 정돈된 백로그만 남습니다.

PAT 고통 없는 안전한 GitHub App 연동

조직(Organization)이 늘어날 때마다 복잡하게 토큰을 재발급받을 필요 없이, GitHub Device Flow 기반으로 안전하게 동작합니다.

스마트한 개발자 경험

작지만 강력한 기능들

매일 AI를 끼고 코딩하는 엔지니어의 피로도를 0으로 만들기 위해 세심하게 설계되었습니다.

클립보드 스마트 파싱

클립보드에 담긴 마크다운의 첫 번째 헤딩(#)을 이슈 제목으로 추출하고 나머지를 깔끔한 본문으로 자동 분리합니다.

다중 조직 & 멀티 레포

GitHub App Device Flow 방식을 사용하여 복잡한 토큰 교체 없이 여러 조직의 비공개/공개 레포지토리에 자연스럽게 발행합니다.

내장 진단 도구 (diagnose)

토큰 유효성, 레포 쓰기 권한, 앱 설치 상태를 ai-issue diagnose 한 번으로 즉시 진단합니다.

안전한 드라이런 (--dry-run)

실제로 GitHub에 이슈를 등록하기 전에 파싱된 제목과 본문 마크다운을 터미널에서 사전에 안심하고 점검하세요.

비대화형 플래그 지원

스크립트나 단축키로 쓸 때는 ai-issue --ai claude처럼 인자를 전달해 프롬프트 없이 즉시 발행할 수 있습니다.

가벼운 단일 바이너리 (Go)

외부 런타임 없이 초고속으로 실행되는 순수 Go 바이너리입니다. macOS, Linux, Windows를 기본 지원합니다.

간편 설치

선호하는 패키지 매니저로 설치하세요

Homebrew, Debian/Ubuntu APT, 또는 Go toolchain을 통해 손쉽게 설치할 수 있습니다.

brew install replworks/tap/ai-issue

macOS 및 Linuxbrew 환경에 가장 권장되는 설치 방법입니다.

APT Terminal Commands 
sudo mkdir -p /etc/apt/keyrings
curl -fsSL https://apt.repl.net/replworks.gpg | sudo tee /etc/apt/keyrings/replworks.gpg >/dev/null
echo "deb [signed-by=/etc/apt/keyrings/replworks.gpg] https://apt.repl.net stable main" | sudo tee /etc/apt/sources.list.d/replworks.list
sudo apt update
sudo apt install ai-issue

클립보드 유틸리티(xclip, xsel, wl-clipboard)가 함께 자동 구성됩니다.

go install github.com/replworks/ai-issue/cmd/ai-issue@latest

Go 1.22+ 개발 환경에서 소스로부터 직접 컴파일하여 설치합니다.

Step 1. 최초 1회 로그인
ai-issue login

브라우저가 열리면 화면에 표시되는 8자리 디바이스 코드를 입력하여 안전하게 토큰을 발급받습니다.

Step 2. 깃허브 앱 설치 & 권한 확인
GitHub App 설치하러 가기

이슈를 등록할 레포지토리에 앱을 설치하고, ai-issue diagnose로 상태를 검증하세요.
